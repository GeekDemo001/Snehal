# Snehal Portfolio

Professional portfolio website for governance, compliance, and AI governance experience.

## Project Files

- `index.html`
- `about.html`
- `portfolio.html`
- `contact.html`
- `style.css`
- `scripts.js`
- `Data/Image.jpeg`
- `vercel.json`

## Deploy to Vercel

1. Push this project to a GitHub repository.
2. Go to Vercel and click `New Project`.
3. Import your GitHub repository.
4. Keep framework as `Other` (or static site auto-detect).
5. Click `Deploy`.

## Local Check Before Push

1. Open `index.html` in browser and test all menu links.
2. Confirm profile image loads.
3. Check mobile view in browser dev tools.
